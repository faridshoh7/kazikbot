# kazikbot — Telegram-бот GRAM

Игровой Telegram-бот на [aiogram 3](https://docs.aiogram.dev/) с внутриигровой валютой **GRAM**
(не криптовалюта). Данные хранятся в локальной SQLite-базе.

## Что умеет

- **Рулетка** — ставки на числа, цвета и диапазоны, раунды с общим банком
- **Мины** — поле с минами, множитель растёт с каждой открытой клеткой
- **Джокер** и **дуэли** между игроками с кулдауном и лимитом в сутки
- **Хогвартс** — прокачка характеристик за галеоны
- **Кланы**, **турниры** участников и чатов, **казна**
- **Профиль**, история операций, переводы между игроками, ежедневный бонус
- **Донат** через Telegram Stars и возвраты
- **Админ-панель**: баланс банка, выдача валюты, правка текстов бота на лету
- Автоматический бэкап базы в `backups/`

## Установка

```bash
git clone git@github.com:faridshoh7/kazikbot.git
cd kazikbot

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

## Настройка

Скопируй пример и впиши свои значения:

```bash
cp .env.example .env
nano .env
```

### Переменные окружения

| Переменная  | Назначение                         |
|-------------|------------------------------------|
| `BOT_TOKEN` | Токен бота, выдаётся у @BotFather  |

Остальные настройки — не секретные — лежат в `config.py`: `ADMIN_ID`, стартовый баланс,
размер банка, ссылки на чат и канал, параметры дуэлей и турниров.

## Запуск

```bash
source venv/bin/activate
python3 main.py
```

База `gram.db` создаётся автоматически при первом запуске.
Второй экземпляр бота запуститься не даст `single_instance.py`.

## Обновление на сервере

```bash
./deploy.sh
```

Скрипт забирает свежий код, доустанавливает зависимости и перезапускает бота.

## Структура

```
main.py            точка входа, регистрация роутеров
config.py          настройки, читает BOT_TOKEN из .env
database.py        работа с SQLite
admin_db.py        админские операции с базой
backup.py          резервные копии базы
roulette_core.py   логика рулетки: разбор ставок, розыгрыш
captcha_core.py    генерация кода и картинки капчи для бонуса
handlers/          обработчики команд и кнопок по разделам
texts.py           тексты сообщений
keyboards.py       клавиатуры
```

## Что не хранится в репозитории

`.env` с токеном, боевая база `gram.db`, папка `backups/` и `__pycache__/` —
всё это в `.gitignore` и живёт только на сервере.

## Запуск как сервис

В репозитории лежит `kazikbot.service`. Установка:

```bash
sudo cp kazikbot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now kazikbot
```

Логи: `journalctl -u kazikbot -f`
